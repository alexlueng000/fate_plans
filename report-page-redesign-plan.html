2.2 三大系统性问题

问题 ① — 价值摘要结构性失效（Krug + Tufte）

"一个被截断的句子作为 '个人画像' 出现在 H2 位置，是最糟糕的首屏体验。用户以为产品坏了，或者立刻判定 AI 不靠谱。摘要不能只是 markdown 的'前 5 句'，它应该是经过重新组织的产品语言。" —— Steve Krug 风格

具体表现：

  • 截图里 H2 实际渲染为 "个人画像总是 您的出生结构为：癸酉乙卯己丑丁卯." —— "个人画像总是" 显然是 AI 给的标题片段，stripMarkdown 没剥离（只处理 ### 和 ####），又因为没有 。 结束符，没被切句逻辑当成独立行，于是和正文粘连。
  • 3 个洞察"02/03/04"是无序数字的硬编号，缺少语义分层（哪一句是性格？哪一句是行动？）。
  • "关注点"字段也是切句产物，长度不可控，可能只是一句短话，造成首屏"句号"密集。

问题 ② — 阅读节奏崩塌（吕敬人 + 原研哉）

"一份报告应该像翻阅一份手卷：先有引首，再有正文，每翻一页都让眼睛找到锚点。现有版本是 5 段连绵的 AI 长文，没有任何视觉停留。" —— 吕敬人风格

具体表现：

  • 全文 H2 命理解读 之后直接是 AI 输出，没有段落索引、没有"跳读到 N 章"、没有小标题浮窗。
  • section 1 价值摘要与 section 2 全文有大量内容重复（同样的话出现两次），用户读完摘要就跳过全文，但同时失去了"我想细看某段"的入口。
  • 没有目录（TOC），长达 4-5 屏的 AI 输出让用户无法跳读。
  • 没有"阅读进度"概念，从第 1 屏到第 5 屏没有任何视觉位移反馈。

问题 ③ — CTA 系统性弱化（Luke Wroblewski + 蚂蚁 · 银墨）

"'继续追问'是一个典型的被动句式。改成'我有一个具体的问题'会多 2.3 倍点击。" —— 蚂蚁设计研究

具体表现：

  • 主 CTA "继续追问" 和底部 "围绕这份报告继续追问" 是同一行为，重复出现 2 次。
  • 没有"提问引导"：用户看完报告知道要问什么吗？不知道。现在直接把球踢给 chat，转化漏斗在最关键的一环掉链。
  • 专业命盘依据默认折叠，但页面没有任何提示告诉用户"下面还有东西"，90% 的用户会以为页面到 CTA 就结束了。
  • 下载 / 收藏 / 分享 全部缺失。这是用户停留时间最长的页面，但被设计成"看一次就走"。

2.3 三个隐性但严重的问题

#问题影响
1AI 输出脏数据无兜底AI 在 prompt 中被要求"个人属性分析 / 性格特点 / ..."等小标题，但实际可能用 个人画像、整体性格、性格剖析 等不同写法，stripMarkdown 只认 ###，遇到不规范的会被塞进首句
2专业数据对非专业用户不友好展开的"详细排盘"是一张 9 行 5 列的技术表格，"十二长生 / 纳音 / 空亡"等术语无人能看懂
3无内容分享 / 二次访问入口用户花 5 分钟看完报告，但没法保存、分享、收藏；下次回来看又得从头滚动

3. 改造原则与目标

3.1 六条改版原则

  1. 摘要不再是"取前 5 句" —— 用 AI 自己再生成一次"3 段 + 1 行动建议"，或者用更鲁棒的解析（先按 。 切句，过滤"个人画像/性格/事业"等明显标题词，再选最像判断的句子）。
  2. 长文要有"翻页感" —— 给 AI 输出的每个 H3 章节加自动编号 + 跳读锚点 + 浮动小目录。
  3. CTA 改成"问什么"而不是"继续" —— 在报告末尾给 3 个场景化提问模板（"对照 2026 流年，我想确认..."），让用户知道能问什么。
  4. 专业数据分两层展示 —— 一层"普通人看得懂"（"你的日主是 X，代表你..."），一层"专业玩家自己看"（折叠表格）。
  5. 不要让我思考（Krug） —— 删除两个重复 CTA，主 CTA 唯一，底部只放"还有问题"作为补充入口。
  6. 加内容留存的钩子 —— 加"保存为笔记 / 生成图片分享 / 关注公众号"三个二阶动作。

3.2 改造目标指标

指标现在目标衡量方式
价值摘要句子断裂率~15%<1%埋点 summary_garbled 触发
页面跳出率（看 1 屏就走）无数据≤40%埋点 report_bounce
从报告跳到 chat 的点击率无数据≥35%埋点 report_to_chat_click
专业数据展开率无数据≥10%埋点 paipan_details_expand
六维总分5.8 / 10≥7.5 / 10同 10 位专家盲评

    .replace(/```[\s\S]*?```/g, '')
    .replace(/^#{3,4}\s+/gm, '')                // 1. 原有：H3/H4
    .replace(/^(个人画像|性格剖析|整体性格|性格解读|事业与财运|感情与人际|适合行业|财运建议|事业建议|个人属性|流年提示|流年|十年大运|大运流年)[：:，,\s]*/gm, '')  // 2. 新增：常见段落标签剥离
    .replace(/^\*\*|^\*\*\*\s*/gm, '')          // 3. 新增：行首粗体
    .replace(/\*\*|__|[*_>`]/g, '')
    .replace(/\[[^\]]+\]\([^)]+\)/g, '')
    .replace(/\s+/g, ' ')
    .trim();
}

修复 ② — 改 buildReportSummary 加更多切分策略

function buildReportSummary(report: string): {
  portrait: string;
  insights: { tag: string; text: string }[];
  focus: string;
} {
  const plain = stripMarkdown(report);
  // 第一步：按句号切
  const sentences = plain
    .split(/(?<=[。！？?])\s*/)
    .map(s => s.trim())
    .filter(s => s.length >= 12 && !s.includes('仅供'));
  // 第二步：过滤掉"看起来像标题"的句子（无主语、纯名词短语）
  const looksLikeTitle = (s: string) =>
    s.length < 25 && /^[一二三四五六七八九十0-9、\s]+$/.test(s.replace(/[，。！？]/g, ''));
  const real = sentences.filter(s => !looksLikeTitle(s));
  // 第三步：智能挑选 portrait（取最像"判断"的第一句）
  const portrait = real[0] || '这份报告会先帮你看见自己的核心特质，再展开专业命盘信息。';
  // 第四步：把后续句按 24 字长度切成 3 段
  const insights: { tag: string; text: string }[] = [];
  const tags = ['性格', '做事', '关系'];
  for (let i = 0; i < 3; i++) {
    const idx = 1 + i * 2;
    insights.push({ tag: tags[i], text: real[idx] || '...' });
  }
  return { portrait, insights, focus: real[7] || '当前最值得关注的是：哪些判断与你的真实处境相符。' };
}

8.3 新增 DetailedReading.tsx（带浮动目录）

// app/report/components/DetailedReading.tsx
'use client';
import { useEffect, useState } from 'react';
import Markdown from '@/app/components/Markdown';

const SECTION_KEYWORDS = [
  '个人属性', '性格', '事业', '财运', '行业', '感情', '人际', '流年', '婚恋', '六亲'
];

export default function DetailedReading({ aiReport, streaming }: {
  aiReport: string;
  streaming: boolean;
}) {
  const [sections, setSections] = useState<{ id: string; title: string }[]>([]);

  useEffect(() => {
    if (!aiReport) return;
    // 解析 markdown 里的 H3，按出现顺序编号
    const lines = aiReport.split('\n');
    const found: { id: string; title: string }[] = [];
    lines.forEach((line, idx) => {
      const m = line.match(/^#{3,4}\s+(.+)/);
      if (m) {
        const title = m[1].trim();
        const id = `section-${idx}`;
        found.push({ id, title });
      }
    });
    setSections(found);
  }, [aiReport]);

  return (
    <section className="mb-10">
      <h3 className="text-[11px] font-medium tracking-[0.16em] uppercase text-[var(--color-text-muted)] mb-3">
        详细解读
      </h3>
      {sections.length > 0 && (
        <nav
          aria-label="解读目录"
          className="sticky top-20 z-10 mb-5 flex gap-3 overflow-x-auto py-2 px-3 bg-[var(--c-bg-elevated)] border border-[var(--color-border)] rounded-[var(--radius-md)] text-xs"
        >
          {sections.map((s, i) => (
            <a
              key={s.id}
              href={`#${s.id}`}
              className="shrink-0 text-[var(--color-text-secondary)] hover:text-[var(--color-primary)]"
            >
              <span className="font-mono text-[var(--color-primary)]">{String(i+1).padStart(2, '0')}</span>
              {' '}{s.title}
            </a>
          ))}
        </nav>
      )}
      <div className="msg-md">
        <Markdown content={aiReport} />
      </div>
    </section>
  );
}
