## 〇、结论先行（TL;DR）

1. **小红书角色 = 拉新 + 种草**，不是付费转化。第一任务是"让一个完全不认识你的人停下来"。
2. **致命前提**：品牌核心词「八字」在小红书是**高危违禁词**（2026 审核已升级，机器+人工双重校验，谐音/拼音/拆分字都能识别）。小红书必须**去八字化**，主打「东方性格观察」。
3. **一句话定位**：小红书上的易凡小师弟，是一个"用出生时间 + 传统文化视角，聊性格、聊惯性、聊人为什么这样"的性格观察账号，**不是命理账号**。
4. **变现走平台内闭环**：小红书开店卖测评/资料（引流款 0.99–9.9 元），严禁站外导流。

## 一、平台认知：小红书和公众号的本质差异

| 维度 | 公众号 | 小红书 |
|---|---|---|
| 用户关系 | 订阅关系，主动找 | 推荐 + 搜索，被动刷到 |
| 第一动作 | 读完文章 | **看封面 + 标题，1 秒决定停不停** |
| 内容形态 | 2000–3500 字长文 | 4–8 页图文，单页 ≤60 字 |
| 情绪基调 | 深度、留白、讲道理 | 强共鸣、金句、姐妹式 |
| 审核红线 | 相对宽松（八字文化可用） | **极严**（八字/命理/算命全高危） |
| 商业闭环 | 外链跳网站 | 平台内开店，禁站外导流 |

**结论**：公众号的内容不能直接搬。同一个选题，公众号讲"观点和体系"，小红书只讲"戳中你的那一句 + 一种新视角"。

## 二、战略定位：小红书在双产品漏斗中的位置

```
小红书（发现：让人停下来 + 记住"易凡小师弟"）
        ↓ 性格测试互动 → 引流性格测试站（浅水区，3分钟零门槛）
性格测试站（拉新主力，结果页埋"想更深入？"）
        ↓
fateinsight.site（深水区，付费转化）
        ↓ 付费用户回流
公众号（信任沉淀，长期留存）
```

- **小红书只负责把"对东方性格感兴趣的人"捞进来**，具体深度解读交给测试站和网站。
- **两个产品在小红书的角色**：
  - 性格测试站 → 小红书的**内容素材 + 互动钩子**（测试类笔记天然高互动）。
  - fateinsight → 不直接推（含"八字/命理"属性，站外链接也违规），靠品牌词"易凡"让用户自然去搜。

|---|---|---|
| 八字文化 | 八字 | **东方性格 / 出生时间看性格 / 性格底色** |
| 八字排盘 | 排盘 | 生成性格报告 / 出生信息分析 |

| 改运 | 改运 | 自我觉察 / 调整行动 |

| 日主/十神/伤官/七杀 | 玄学黑话 | 翻译成"性格特质"再讲 |

### 5.3 用词三原则（每篇都过一遍）

1. **标题、封面、首图：绝对不用「八字/命理/算命/运势」任何一字。**
2. **正文科普：用「出生信息 / 四柱」替代「八字」；若必须提，控制低频 + 注明"传统文化视角" + 不配排盘。**
3. **所有引流词：用「东方性格报告 / 性格底色」替代「八字报告」。**

> 💡 核心思路（沿用 08-25 文档并升级）：
> **让用户从"自己"进入，而不是从"八字"进入。**
> 标题问"为什么你越焦虑越想控制"，正文才讲传统里的"某种性格特质"。
> 删掉所有命理词后，话题本身仍值得普通人看——这就是安全内容。

## 七、内容形式与封面规范

### 7.1 内容形式
- **主力：图文笔记（4–8 页）**，一人运营成本最低，也最符合小红书"图文重灾区、审核严"的生态。
- 单页文字 ≤60 字，多用短句 + 金句排版。
- 可少量混发 1 分钟口播短视频（观点类），但不作为主力。

### 7.2 封面规范（决定点击率的生死线）
| 项 | 规范 |
|---|---|
| 尺寸 | 3:4（1080×1440px） |
| 主色 | 朱砂红 `#B54434` + 暖米白底（品牌统一） |
| 字体 | 思源宋体（Noto Serif SC），标题加粗 |
| 标题字数 | ≤12 字，情绪钩子 / 反常识 / 数字 |
| 风格 | 古风插画 + 现代元素混搭，柔和底色，信息流里高辨识度 |

**封面标题公式**：
```
[情绪钩子 / 反常识] + [具体人群] + [好处/数字]
示例：
- "越焦虑的人，越爱控制"（情绪）
- "做决定前，你必须先想明白这件事"（悬念）
- "30秒，看出你的性格底色"（互动）
```

## 十、引流与变现合规路径（分阶段，重点）

> ⚠️ 小红书严禁站外导流（微信/公众号/二维码/链接），玄学赛道举报率最高、封号最快。变现必须走**平台内闭环**。

### 阶段一（0–500 粉）：纯内容，0 变现
- 简介只写定位，不放任何联系方式。
- 不回复任何"私聊/加微信"请求。
- 目标：把"易凡小师弟"做成可搜索的品牌词。

### 阶段二（500–3000 粉）：开店卖测评/资料
- 开小红书店铺，上架虚拟产品（引流款）：
  - 0.99 元：性格底色速测（10 题精简版）
  - 9.9 元：东方性格完整报告（测试站同源内容）
  - 9.9 元：情绪日志模板（心镜灯同源）
- **平台内交易闭环**，同时测试用户付费意愿（为测试站定价打样）。

### 阶段三（3000 粉+）：承接测试站上线，深水区导流
- 笔记引导"搜'易凡'做完整测试"（品牌词，不直接放链接）。
- 深水区用户（fateinsight）通过"全网同名"自然搜索转化，**不主动站外导流**。

### 红线提醒
- 评论区、私信绝口不提"微信/公众号/加V"。
- 只解答泛化问题，不做个人具体命理分析。
- 不用谐音、拼音、拆分字规避（2026 已能识别，反而加重处罚）。

## 十三、一人运营产能建议

创始人独自运营（开发+内容+运营+客服），产能必须克制：

| 平台 | 每周产出 | 备注 |
|---|---|---|
| 小红书 | 4–5 条 | 图文为主，单条 30–40 分钟 |
| 公众号 | 2 篇 | 深度长文，周末集中写 |
| 知乎 | 1–2 个回答 | 复用研究素材，低频 |

**复用工作流（沿用 08-25 文档）**：
```
周末定 2–3 个核心主题 → 研究透 → 拆成：
小红书（情绪入口） + 公众号（观点深化） + 知乎（知识回答）
```
不是写 40 篇完全不同的内容，而是研究 10 个主题，分发成 40 份不同形态。

**小红书运营优先级（P0）**：
1. 建号 + 写简介（去八字化）
2. 做 3 套封面模板（朱砂红 + 思源宋体）
3. 按支柱①先发 5 篇性格观察，测内容模型
4. 找到爆款公式后，再开店铺上引流款
