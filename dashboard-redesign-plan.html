二、核心问题诊断（三大系统性问题）

问题 1：视觉权重倒置——锦上添花占了主位

"今日八字提示"是通用运势建议，信息密度低但占满首屏宽度且紧跟 header。而真正承载"续作价值"的 ContinueLastCard 被压在下面。用户进来第一眼看到的不是"我上次的事"，而是"今天适合做什么"。

当前顺序

  1. Header
  2. 今日八字提示（占满宽度，三栏）
  3. 当前最适合继续（续作卡片）
  4. 新开分析 x2
  5. 最近记录
  6. 底部三入口

改版后顺序

  1. Header（含进度条）
  2. 当前最适合继续（主CTA，最大视觉）
  3. 新开分析（单行二选一）
  4. 最近记录（加状态标签）
  5. 今日八字提示（压缩为单行条）
  6. 底部三入口（折叠到右上角）

问题 2："算法报告体"文案——不是朋友在跟你说话

ContinueLastCard 中的摘要文本：上次判断 / 当前卡点 / 推荐下一步——这是系统输出格式，不是人在跟你聊天。用户刚登录就被"判断/卡点/下一步"包围，情绪上是负担。

问题 3：重复入口导致决策瘫痪

首屏存在 3 个"去分析"入口：ContinueLastCard 的"继续分析"、"开始八字分析"、"起一卦"。其中"八字长期趋势"卡片与 ContinueLastCard（当 type=bazi 时）信息明显重复——用户看到两个相似入口会犹豫"我该点哪个"。

三、新信息架构：四层金字塔

遵循 Don Norman 的"心智模型优先"和 Julie Zhuo 的"dashboard = 客厅"原则，将模块按用户回访时的心理优先级重新排列：

L1 - 续作层（首屏 70% 视觉权重）

当前最适合继续 -- "你上次问的事，接着聊"

主 CTA / 最大卡片 / 含上次摘要 + 继续按钮

v
L2 - 开启层（次屏 / 简洁二选一）

新开分析 -- "想看另一件事？" -> 八字 / 六爻

单行横排 / 不再占大块面积

v
L3 - 回顾层（第三屏）

最近解读记录 -- 带状态标签 + "聊到第几轮"

5 条列表 / 进行中/已完结 / 可继续追问

v
L4 - 锦上添花层（底部 / 压缩为单行条）

今日八字提示 -- 单行横条，不再占三栏大卡

农历 + 一句话提醒 / 点击可展开详情

设计哲学：用户回到 dashboard 时，最强烈的需求是"我上次做的事到哪了"，而不是"今天运势如何"。运势是锦上添花，续作是核心价值。

五、新文案规范

5.1 语气原则

原则说明示例
对话感 > 报告体像朋友在跟你聊天，不是系统在输出报告"接着聊" > "继续分析"
正向 > 否定正面表述，不用"不是...而是...""多一个看问题的角度" > "不是替你决定"
具体 > 抽象用可量化的词"3 分钟""第 4 轮""本月 7 次"
口语 > 书面正常人说话的用词"问一件事" > "判断一个具体事项"
你 > 我们主语永远是"你"不是"系统""你上次问的是" > "上次判断："
