PART 01

设计语言规范

改版不是推翻，而是把已经做对的 60%（调性、留白、网格）固化成规范，再补上缺失的 40%（字重、形系统、转化组件）。以下规范对首页及全站生效。

规则：一屏之内朱砂红面积 ≤ 10%；红色只出现在"可点击 / 需注意"的元素上；正文永远用墨黑，不用纯黑 #000。

规则：标题用宋体（衬线，文化感），辅助说明用黑体（无衬线，工具感）；层级靠"字重差 + 字号差"双重拉开，不再只靠字号。

1.3 形系统

空心黑细圆 = 序号、分步标记。线宽统一 1.5px。
卡片圆角统一 8px；删除页面中所有装饰性小圆点。
镜
朱砂印章（圆角 4px）= 品牌专属符号，只用于格言区与页脚。

1.4 动效系统

  • CTA 悬停：背景 #B54434 → #9A3826，上移 2px，阴影 0 4px 12px rgba(181,68,52,.25)，过渡 0.2s ease
  • 卡片悬停：边框 #E0DBD0 → #B54434（40% 透明度），右上角浮现箭头 →，过渡 0.25s
  • 链接悬停：下划线从 0 → 100% 宽度展开，0.2s
  • 滚动进场：区块 fade + 上移 16px，只进场一次，尊重 prefers-reduced-motion
  • 禁止：弹跳、旋转、闪烁、视差。东方调性 = 克制的动效

PART 03

落地实施清单

按优先级分四批执行。P0 全部是文案与样式改动，一个人一天内可完成上线；P1 需要前端开发；P2/P3 排入常规迭代。

P1 · 本周统一形系统：空心圆序号、卡片圆角 8px、删除装饰圆点；菜单 15px；心镜灯 tooltip品牌一致性 +20%前端 0.5 天

全站文案红线自查
